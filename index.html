What this site is

A chapter-based, hands-on path to designing WebSocket APIs well, built around a single AsyncAPI 3 contract for a shipping and cargo domain. The socket here pushes a live handling-event feed — the stream of container moves, customs holds, and delivery confirmations a shipment generates as it moves — to any client watching a booking, instead of making that client poll the sibling REST booking service for a status that hasn't changed. Every hands-on chapter ships the same example in both Quarkus WebSockets Next and Python (FastAPI/Starlette plus the native websockets library), generated against that one contract. You work through message design and versioning, backpressure and flow control, heartbeats and reconnect — both stateless and Kafka-backed — security, fan-out contrasted on Kafka and on Redis, binary Protobuf framing, testing and debugging a protocol you can't just `curl`, and the anti-patterns that show up once a socket is in production. It assumes you can read Java and Python; it is not a tutorial in either language. The code tabs are built to admit Go and C++ later. All container images are UBI-based, and the stack runs on Docker Compose, minikube, and OpenShift Local.
